# Lane Weng Portfolio — GitHub Pages

Upload the contents of this folder to the root of a GitHub repository configured for GitHub Pages.

## Entry point

- `index.html` is the GitHub Pages homepage.
- `lane-weng-portfolio-preview.html` is kept as a compatibility copy for existing internal links.

## Before publishing

In `index.html`, change the Resume link from the local `file:///Users/...` path to:

`resume-designer-sep.png`

All project pages and asset folders are included with their existing relative paths.
